# PROJECT ZERO v5 — Getting started

Same as always. Nothing new to install (the map loads its library + tiles from the internet at runtime).

```
cd Desktop\project-zero
python dashboard.py
```
(`python3` if needed. Ctrl+C stops.) Browser opens http://localhost:8177.

## Six tabs now
1 **Discover** — startup sources (unchanged v4.1 workflow: Find New Candidates → Reject/Research/Keep).
2 **Pipeline & verify** — scoring, Provisional/Verified, memos, emails (unchanged) + **Send to Omar** button in every company drawer + **Weekly update for Omar** button in the toolbar.
3 **People** — your Talent Graph. Add everyone worth remembering. Open a person → bottom box = the ritual: *"Who are the three most talented people you know?"* → three names → one click creates them linked, chain preserved. Overdue follow-ups turn red.
4 **Events** — Scan event sources (Luma city pages, KIT/ETH/EPFL/UnternehmerTUM/Pioniergarage, Devpost, MLH, Google/AWS/NVIDIA) → leads → convert to events. Every event gets an evidence-based Event Score /100 (auto-suggested, you adjust). After attending: **Debrief** → people met become Person records, startup leads land in Discover.
5 **Map** — the control room. Startups (circles, colored by stage, ring = sent to Omar) + events (orange squares) on a calm Positron map, clustered. Filters: time, distance from Karlsruhe, stage, sector score thresholds. Click a pin → right intelligence panel → jump to full profile.
6 **Project A Radar** — unchanged: verified-only Top 10, Research Queue, conflict-gated.

## The v5 weekly rhythm
Mon: Discover + Scan events + 30 min manual sources. Tue–Thu: act by fundraising timing; add every person you meet. Event day: go, then 2-minute Debrief. Fri: verify, Generate Radar, **Weekly update for Omar** → copy → email.

Rules unchanged: verified beats provisional, conflicts go to Omar first, recently funded = low urgency, never present yourself publicly as Project A Scout (Porsche/automotive positioning — the tool's Omar outputs are the only place the scout identity appears).
